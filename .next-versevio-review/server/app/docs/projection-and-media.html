Projection, slides and live video

Control the output window and show your service media.

Set up the screen

  1. Connect the external display and check Windows display settings before opening VerseCue's output.
  2. Choose the target display in Preferences → Projection. Save your changes, then use Go Live.
  3. With one display, projection opens as a normal window. Rehearse movement and visibility so it does not block the operator workspace.

Prepare service media

  1. Use Songs to prepare lyrics and queue song sections. Scripture and song queues are separate.
  2. Import a supported PowerPoint file in Presentations and review its slides before display.
  3. Use Videos to select a local video. Check volume, repeat and blackout behavior in rehearsal.
  4. Choose an available live camera, capture or screen source. Its dashboard shortcut follows the selected source, with full-screen and behind-text options.
